# Alpha Laundry

A modern, modular Python web application for laundry management.

## Quick Start

```bash
cd laundry_app
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Visit `http://localhost:5000`
